# Médecine.

| Jet (d100) | Résultat                                                                                                 |
| ---------- | -------------------------------------------------------------------------------------------------------- |
| **1-5**    | Intervention divine / destin : sauvé par un miracle (artefact, pouvoir latent, intervention MJ).         |
| **6-10**   | Aucune conséquence : évite la mort de justesse, revient à 1 PV.                                          |
| **11-25**  | Coup de chance : seulement sonné, inconscient quelques minutes. Pas de séquelle.                         |
| **26-40**  | Blessure légère : égratignure, bleus, petit saignement. Petit soin et peut repartir.                     |
| **41-55**  | Blessure modérée : coup dur, entaille, entorse. Douleur mais jouable avec malus légers.                  |
| **56-65**  | Blessure sérieuse : plaie profonde, commotion, côte brisée. Désavantage aux actions physiques.           |
| **66-75**  | Blessure grave : membre cassé, hémorragie sévère, brûlure étendue. -3 à toutes les actions jusqu’à soin. |
| **76-85**  | Blessure critique : incapacité totale (membre arraché, colonne touchée). Stabilisation possible.         |
| **86-95**  | Agonie : mourant, perd connaissance en 1d4 minutes sans aide.                                            |
| **96-100** | Mort instantanée (coup fatal, décapitation, explosion totale).                                           |
